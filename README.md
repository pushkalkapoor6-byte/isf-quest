# ISF Quest - MR product tanker 3D training walkthrough

Interactive 3D model of a generic 50,000 dwt MR product tanker for ISF Group maritime training. Draft, pending SME sign-off.

Built in Blender, rendered in the browser with three.js. Open `index.html` via the GitHub Pages link.
